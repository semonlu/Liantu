# 渐进超负荷与失败回退

一句话结论：进阶可以表现为更高重量、更多次数、更多高质量工作或相同输出下更低 RPE，而不是每周强制加重。

解决什么问题：怎样用主要动作 1RM 生成保守的开局重量，主项、次级动作和辅助动作分别怎样进阶，以及失败后如何回退。

不解决什么问题：不能根据一次训练失败判断长期停滞，也不保证无限线性增长。

关键变量：目标次数区间、目标 RPE、实际负荷、完成率、连续失败次数和 e1RM。

适用人群：新手主项可使用小幅线性进阶；辅助动作和多数增肌动作使用双重进阶；中级训练者结合训练块与 RPE。

如何监测：首次使用保存规范动作的 1RM；之后按动作而不是整场训练追踪实际重量、计划/完成组数和最近三次 RPE。

什么时候增加：达到全部组的次数上限并低于目标 RPE；上肢器械通常小幅增加，下肢器械允许更大但仍受可用配重档限制。

什么时候保持：完成最低目标但未达到次数上限，或 RPE 已接近目标。

什么时候降低：同一动作连续两次低于最低次数或连续高 RPE；降低约 5%-10% 后重新爬升。

证据等级：进阶总原则为 A；Liftosaur 仅作为 C 级行为设计参考，不复制其 AGPL 实现。

仍有哪些不确定性：最佳加重幅度取决于器械档位、动作和训练水平。
